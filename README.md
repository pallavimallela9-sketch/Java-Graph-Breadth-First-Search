# Breadth First Search

A Java program to traverse a graph using Breadth First Search (BFS).

## Features

- Creates an undirected graph
- Takes a starting vertex
- Traverses the graph level by level
- Displays the BFS traversal

## Technologies Used

- Java
- ArrayList
- Queue
- Scanner

## Concepts Used

- Graph
- BFS
- Queue
- Adjacency List
- Visited array

## Output

BFS Traversal: 0 1 2 3 4
